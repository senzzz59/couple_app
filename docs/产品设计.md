# us. 产品与设计文档

> 给情侣用的 App：每一对有自己的私密空间，记录一起吃过的店、重要的日子、日常的小瞬间。
> 设计方向：**可爱简约风（草莓牛奶）+ 处处有回应的果冻动效**。

---

## 2. 设计语言：草莓牛奶（可爱简约风）

### 2.1 原则

参考 Dribbble 上评价高的 kawaii / cute-minimal 作品总结出的规律：**可爱靠角色和形状，不靠堆颜色**。

1. **一个色系**：全 App 只用粉色（从浅到深）+ 一点蜜桃色点缀。不再给每个模块配不同颜色——五颜六色的马卡龙卡片会显得廉价。
2. **白卡片为主**：卡片默认白色，颜色只给「主角」：首页「在一起」大卡（浅粉）、每日一问（蜜桃）、按钮、图标底。
3. **团子小人当主角**：两个会眨眼、会晃的团子（她：草莓粉 + 蝴蝶结；他：蜜桃奶油 + 小芽）出现在登录页、首页、空状态、App 图标上。装饰一律用平涂矢量（小爱心、小圆点），不用 emoji 当装饰。
4. **圆体字**：数字和英文用 Nunito，中文标题 / 粗体用思源柔黑（圆体），正文用系统字体；不用渐变、不用衬线体。
5. **果冻手感**：按下时纵向压扁、横向微胖，松手后像果冻一样晃回来；入场动画带一点回弹。

### 2.2 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `bg` | `#FFF7F5` | 页面底色（草莓牛奶白） |
| `surface` | `#FFFFFF` | 卡片 |
| `ink` | `#4B2E35` | 主文字（带粉调的暖棕，比纯黑柔和） |
| `muted` | `#B48A92` | 次要文字 |
| `accent` | `#F27B96` | 草莓粉：爱心、勾选、进度、装饰 |
| `accentStrong` | `#E5627F` | 按钮、加号（白字要清晰） |
| `pink` | `#FDE2E8` | 浅粉：首页大卡、图标底、选中态 |
| `peach` | `#FCE8DA` | 蜜桃：每日一问、美食卡、少量点缀 |
| 小人 | 她 `#F9B4C4` / 他 `#FBD5BF` | 腮红 `#F27B96`，眼睛 `#4B2E35` |

### 2.3 字体、圆角、阴影

- 数字 / 英文：Nunito 800–900。
- 中文标题、粗体、标签、按钮：**思源柔黑 Resource Han Rounded**（SIL OFL 1.1），裁剪为 GB2312 全部 6763 个汉字 + 常用标点，Bold / Medium 两个字重各约 3MB，按 OFL 要求改名为 UsRounded，许可证在 frontend/assets/fonts/UsRounded-OFL.txt。
- 正文（长段文字、用户内容）：系统字体，读起来更舒服。
- 为什么没用阿里妈妈方圆体：它是可变字体，默认样式是「最细 + 方角」，React Native 在安卓上无法切换到圆角样式，许可也不允许我们转换。
- 圆角：14 / 20 / 卡片 26 / 大卡 34 / 胶囊 999。
- 阴影：粉调、很淡（y=6、blur=14、不透明度 14%）。

### 2.4 动效参数（`src/theme/index.ts`）

| 名称 | 参数 | 用于 |
|---|---|---|
| `soft` | damping 15, stiffness 170 | Tab 指示块、分段选择器、进度条 |
| `snappy` | damping 16, stiffness 320 | 按下压扁 |
| `bouncy` | damping 7, stiffness 240 | 松手回弹、点赞、星星、Toast、盖火漆印 |
| 列表入场 | FadeInDown + spring（damping 13），每项延迟 50ms | 所有列表和卡片 |
| 团子小人 | 每 ~3 秒眨眼一次；1.3 秒一个周期上下晃 + 轻微压扁 | 登录页、首页、空状态 |

## 3. 交互与动效清单

| 位置 | 交互 | 动效 |
|---|---|---|
| 底部 Tab | 点击切换 | 浮动毛玻璃胶囊栏，选中背景块弹簧滑动，选中项文字缩放出现 |
| 中间「+」 | 点击 | 加号旋转 135° 变成 ×，背景毛玻璃淡入，4 个快捷操作从下往上依次弹出 |
| 首页天数 | 进入页面 | 每一位数字像老虎机一样滚到目标值，逐位延迟；右上角爱心上下漂浮 |
| 想你了 | 点击 / 长按 | 爱心持续「心跳」；点击时 8 个爱心粒子向四周飞散；长按展开更多选项 |
| 收到戳一戳 | — | 顶部通知卡片弹簧落下，连续两下重震动；App 在后台时发本地通知 |
| 每日一问 | 提交答案 | 对方答案从毛玻璃状态 3D 翻牌揭晓；两人都答完时放彩带 |
| 动态 | 双击图片 / 文字 | 中间出现大爱心放大后淡出；爱心图标弹跳 |
| 清单 | 勾选 | 勾号框压缩回弹 + 勾号缩放出现 + 删除线从左划到右，0.65 秒后条目淡出、其余条目平滑补位；全部完成放彩带 |
| 清单 | 左滑 | 露出删除按钮 |
| 转盘 | 点击「转！」 | 6 圈以上，贝塞尔减速 4.2 秒，每划过一格触感一次；停下放彩带、结果卡弹出 |
| 店铺详情 | 滚动 | 封面视差（向下拉放大、向上滚慢速移动），滚过封面后顶栏淡入 |
| 登录 | 密码错误 | 表单左右抖动 + 警告触感 |
| 大标题页面 | 滚动 | 大标题淡出，顶部毛玻璃小标题淡入（iOS 风格） |
| 星级评分 | 点击 | 被点的星放大到 1.35 再回弹 |

## 4. 信息架构

```
登录
└─ Tab
   ├─ 首页 ── 设置（头像）/ 纪念日 / 每日一问 / 转盘 / 清单 / 动态
   ├─ 美食 ── 想去 | 吃过 → 店铺详情 → 记录一次 / 编辑 / 导航 / 小红书
   ├─ ＋ ──── 发动态 / 收藏好店 / 加个待办 / 纪念日
   ├─ 动态 ── 发动态 / 评论 / 看大图
   └─ 清单 ── 新建 / 编辑
```

## 5. 数据模型（MySQL）

`users`（两人）· `space`（在一起的日子）· `places`（店）· `visits`（探店记录，照片和菜品存 JSON）· `anniversaries` · `moments` + `moment_likes` + `comments` · `todos` · `answers`（每日一问，每人每天一条）· `nudges`（戳一戳记录）。
表结构定义在 `backend/src/db/schema.ts`，迁移 SQL 在 `backend/drizzle/`。

## 6. 用 AI 生成 / 迭代 UI 的提示词资源

- **DESIGN.md**：起源于 Google Stitch 的做法，用一份文件写清楚设计 token 和设计理由，让编码代理每次生成的页面风格一致（社区库：getdesign.md、designmd.app）。本文件第 2 节就可以直接当 DESIGN.md 用。
- **Mobbin / Muzli**：找真实 App 截图做参考的设计灵感库。
- **Superdesign Prompt Library**：风格 / 动效 / 组件的提示词合集，可在 Claude Code、Cursor 里用。
- 写提示词时只描述页面本身（「首页加一张时光胶囊卡片，用 lilac 底色，点开有信封打开动画」），颜色、圆角、弹簧参数交给设计 token。
