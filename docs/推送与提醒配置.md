# 推送、离线戳一戳和本地提醒

## 网页版消息通知（添加到主屏幕后）

不需要任何配置：后端第一次用到时自动生成 VAPID 密钥并存进数据库 `app_secrets` 表；订阅存在 `web_push_subscriptions` 表，迁移随部署自动执行。想自己指定密钥时，在后端 `.env` 填 `VAPID_PUBLIC_KEY`、`VAPID_PRIVATE_KEY`（`npx web-push generate-vapid-keys` 生成），联系方式可用 `VAPID_SUBJECT`（`mailto:` 邮箱或 `https://` 网址）指定。换密钥后大家要在设置里重新开启一次。

开启方法：设置 → 消息通知 → 开启，系统会弹出通知权限。开启后会自动发一条测试通知。

- iPhone / iPad：需要 iOS 16.4 以上，必须先「添加到主屏幕」并从主屏幕图标打开（Safari、Chrome 都可以添加）。推送走苹果的服务，国内可用。
- 安卓 Chrome：推送走谷歌的服务（FCM）。国内手机没有谷歌服务、或网络连不上谷歌时**收不到**；这种情况只能做独立 App 并接入厂商推送通道。
- 电脑 Chrome / Edge：浏览器开着（可以在后台）就能收到。

什么时候推送：对方没有开着 App（不在前台）时，TA 发动态、评论 / 回复、点赞你的动态、戳一戳、第一次回答当天的每日一问、往相册传照片（10 分钟内只提醒一次）、收藏想去的店、埋时光胶囊。对方正开着 App 时不推送，页面会实时刷新。点通知会打开对应页面。

失效的订阅（推送服务返回 404 / 410）会自动删除。退出登录会取消这台设备的订阅。

## 独立 App（Expo）推送

## 已实现

- 动态使用时间和 ID 组合游标分页，可继续查看更早的动态。评论新增、编辑和删除都会通知双方刷新动态。
- 每日一问的当日查询、提交结果和历史查询都由服务器控制答案可见性。自己没有回答当天题目时，对方的正文返回 `null`。
- 纪念日预排未来三次发生日期，节日覆盖未来三年，并安排后续恋爱里程碑。最多安排最近 59 条提醒，另外保留一条日程续排提醒。打开 App 或数据变化时更新；退出登录时清除本地提醒。
- 独立 App 登录并授权通知后会登记 Expo Push Token。另一半未处于前台实时连接时，服务器通过 Expo Push Service 发送戳一戳；前台保持实时消息。已接受远程推送时，不再重复生成后台本地通知。
- 推送回执存入数据库，后台定期查询实际投递结果，删除失效设备 Token；服务器重启后继续处理待查回执。

## 需要完成的部署配置

1. 在 `frontend` 中运行 `npx eas-cli@latest init`，连接你自己的 EAS 项目。项目 ID 通常写入 `app.json` 的 `extra.eas.projectId`，也可以填入 `.env.local` 的 `EXPO_PUBLIC_EAS_PROJECT_ID`。请使用真实项目 ID。
2. 配置该项目的 iOS APNs 和 Android FCM v1 推送凭据。Android 按 Expo 官方文档添加自己的 `google-services.json` 并配置 `android.googleServicesFile`。这些凭据属于你的 Apple / Firebase 账号，仓库未内置。
3. 重新构建独立 App，在真机上安装并允许通知；不能仅靠浏览器或 Expo Go 验收离线推送。
4. 更新并重启后端。启动时自动运行新迁移，新增 `push_tokens` 和 `push_receipts`，不删除现有业务数据。
5. 如果在 Expo 项目上启用了增强推送安全，在后端 `.env` 填入 `EXPO_ACCESS_TOKEN`。Docker Compose 已支持传递此变量。不启用时可留空。

## 真机验收

- 两人登录：新增评论，另一台前台 App 应立即显示；新增超过 30 条动态后仍能继续浏览。
- 只有一人回答：另一人的 API 响应中该回答 `content` 应为 `null`；回答后显示双方正文，历史查询遵守同一规则。
- 对方 App 在前台、后台、被系统终止三个状态分别发送戳一戳，检查通知是否到达、是否重复。服务器推送回执用于排查凭据或失效 Token。
- 开启通知后检查系统中已安排的提醒；更改日期、完成待办、退出登录后检查提醒是否更新或取消。

本地通知仍受系统数量限制和通知权限影响；提前安排多次不能无限覆盖未来。远程推送还受 APNs / FCM、设备网络和系统设置影响，尤其不含 Google 服务的国内 Android 设备，当前没有接入厂商推送通道。推送服务暂时不可用时保留实时消息，并记录错误；当前没有离线发送重试队列。无网络时退出登录无法立即撤销服务器 Token。
